# Mehrad Laravel DevKit
## Phase 1 — Stabilization & Integration

### Role

Act as a Senior Laravel Architect, Senior Full-Stack Engineer, and Software Quality Engineer.

You are working on **Mehrad Laravel DevKit**, an open-source Laravel development starter kit designed to provide a reusable foundation for building CMS, CRM, administrative dashboards, and other business applications.

Your task is to stabilize the existing implementation, fix architectural and integration issues, and make the project genuinely installable and functional.

This is an existing project, not a greenfield development task.

**Do not rebuild the project from scratch. Do not replace working components without a clear technical reason. Preserve existing design decisions and functionality wherever possible.**

---

# 1. Project Architecture

The intended architecture is:

- Backend: Laravel 12
- Frontend: React
- Language: TypeScript
- Integration: Inertia.js
- Build Tool: Vite
- Styling: Tailwind CSS v4
- UI Components: shadcn/ui and Radix UI
- Database: MySQL
- Development Environment: Docker and Laravel Sail
- Package Management: Composer and npm

The application must remain a Laravel-first monolithic application.

React must communicate with Laravel through Inertia.js.

Do not introduce:
- A separate Node.js backend.
- An independent React application architecture.
- Unnecessary API layers.
- Microservices.
- Additional infrastructure without a demonstrated requirement.

The standalone React preview environment originally generated by Google AI Studio must not be confused with the actual Laravel application.

Laravel must be the authoritative runtime environment.
